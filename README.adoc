Central configuration of the *cuioss-review-bot* reviewer: the open-source
https://github.com/The-PR-Agent/pr-agent[PR-Agent] running on Google Gemini through Vertex AI,
for every repository of the *cuioss* organization that adopts it.

== What this repository is

The organization runs three automated pull request reviewers:

[cols="1,2,2"]
|===
|Reviewer |Central configuration |Role

|CodeRabbit
|https://github.com/cuioss/coderabbit[`cuioss/coderabbit`] (`.coderabbit.yaml`)
|General review, nitpicks, committable suggestions

|Sourcery
|Dashboard (https://app.sourcery.ai[app.sourcery.ai])
|Refactoring and code-quality review

|cuioss-review-bot (PR-Agent)
|*This repository*
|Security- and correctness-weighted review
|===

PR-Agent reads its organization-level settings from `.pr_agent.toml` at the root of this
repository's default branch. It looks the repository up under the hard-coded name
`pr-agent-settings` and reaches `cuioss/cuioss-review-bot` through GitHub's rename redirect, so no
repository named `pr-agent-settings` may ever be created in the organization — see
xref:doc/configuration-precedence.adoc#pr-agent-lookup[How PR-Agent finds this repository].

The reviewer runs as a GitHub Action, the open-source PR-Agent image pinned by digest, from the
organization's reusable workflow
https://github.com/cuioss/cuioss-organization/blob/main/.github/workflows/reusable-cuioss-review-bot.yml[`reusable-cuioss-review-bot.yml`].

== Contents

[cols="1,3"]
|===
|Path |Content

|`.pr_agent.toml`
|The organization-level PR-Agent configuration: models, token budgets, the central review
charter, and the `/improve` tuning.

|`packs/`
|The review charter artifacts: `spine.md` and one pack per domain. Generated in
`cuioss/plan-marshall` and published here; never edited by hand.

|`doc/`
|The documentation listed below.

|`.github/workflows/validate-packs.yml`
|The `Validate settings` check: `.pr_agent.toml` parses and `packs/` is not empty.
|===

== Using it

A repository adopts the reviewer by adding one caller workflow that calls
`reusable-cuioss-review-bot.yml`; nothing from this repository is copied. The caller template is
https://github.com/cuioss/cuioss-organization/blob/main/docs/workflow-examples/cuioss-review-bot-caller.yml[`cuioss-review-bot-caller.yml`].

Without further configuration the reviewer applies the central charter. A repository selects its
own charter — the spine plus the domain packs it names — with a `cuioss-review-bot:` block in
`.github/project.yml`; xref:doc/consumer-guide.adoc[Consumer guide] covers that opt-in from start to
finish.
